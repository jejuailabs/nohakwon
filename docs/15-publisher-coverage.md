# 출판사별 교과서 목차 구축 내역

확인일: 2026-10-15. 대상은 초등학교 4·5·6학년과 중학교 1·2·3학년의 국어·영어·수학·사회·과학이다.

기존 61종을 유지하고 346종을 추가해 **407종·2,514개 대단원**을 제공한다. 초등 184종, 중학 223종이며 2022 개정 314종과 2015 개정 93종을 구분한다. 교육부 국정 교과서를 포함한 20개 발행처다.

## 누락 대조 기준

[한국교과서협회 판매 목록](https://www.ktbookmall.com/)에서 대상 학년·과목의 판매 항목을 품절 여부와 관계없이 수집했다. 이 목록의 18개 출판사·283종은 모두 카탈로그 ID에 연결되어 있다. 원래 판매명, 법인명, 대표 저자, 개정판, 학년, 판매 목록 주소 및 연결 ID는 `apps/web/src/data/publisher-inventory.json`에 보존한다. 미래엔 자체 유통 교재와 국정 교과서는 기존 공식 자료를 유지했다. 판매 목록 외에 출판사가 공개한 추가 판본도 포함한다.

‘전체’는 이 확인일의 대상 판매 목록과 확보한 공개 교과서에 대한 범위다. 미발행 교과서·모든 과거 판본·다른 과목까지 포함한다는 뜻은 아니다. 현재 중3의 2015 개정판과 공개된 2022 개정 중3 판본은 서로 대체하지 않는다.

## 자료 출처와 추출

추가 목차는 `apps/web/src/data/publisher-textbooks.json`에 저장한다. 각 교재의 `sourceUrl`은 식별 정보를 확인한 공개 페이지, `tocSourceUrls`는 차례를 확인한 공식 이미지·PDF·전자교과서·공개 단원 목록이다. `checkedAt`, `tocLevel`도 함께 보존한다. 이 주소는 실제 교재별 주소이며 아래 링크는 출판사별 공개 자료의 입구다.

공개 단원 목록이 있으면 구조화된 값을 우선 사용했다. 이미지·PDF는 차례에 실제 표시된 대단원만 전사하고 페이지 묶음, 대표 저자, 학기/권을 대조했다. 동아출판 영어1 이병민은 공식 스마트 교과서의 단원별 반복 머리말·꼬리말과 단원 시작 페이지를 대조했다. 좋은책신사고 수학3은 출판사가 제공하는 해당 교과서 자습서의 차례와 협회 교과서 식별 정보를 연결했다. 이 두 경우는 데이터의 `verificationNote`로 남겼다.

영어의 Special/Review/Wrap-up, 별도 보완 교재, 프로젝트·정답과 풀이·부록을 정규 대단원에 합치지 않는다. 일반 단원으로 실제 수록된 ‘소중한 우리 땅, 독도’ 등은 그대로 유지한다. 천재교과서 사회②의 공개 미리보기와 현재 단원 메뉴 사이 철자 차이는 현재 출판사 메뉴의 ‘글로컬 시민’을 채택했다.

## 매칭·저장·검증

- YBM/와이비엠, NE능률/엔이능률, 디딤돌/디딤돌교육 및 법인 표기를 정규화한다. 천재교육/천재교과서와 창비/창비교육은 구분한다.
- 같은 출판사의 다른 저자, 2015/2022, 국어 학기, 사회 ①/②, 국정 국어 가/나를 별개 교재로 유지한다. 기존 교재 ID와 학습자 스냅샷은 유지한다.
- 중앙 카탈로그는 Firebase `barum-10aad`의 `textbooks`에 동기화한다. 동기화는 수동 관리 자료를 보존하고 450개씩 나눠 쓴다. 서버 읽기도 페이지별로 처리해 자료 수가 증가해도 잘리지 않는다.
- `npm test`: 전체 판매 목록 283종의 정확한 매칭, 전체 정체성 중복, 출처 보존, 출판사 별칭, 서로 다른 저자·판본의 충돌 방지를 검증한다.
- `node scripts/verify-textbook-matching.cjs --live`: 실제 Firebase 407종의 메타데이터·단원, 283종 매칭, 모든 발행처의 교재 등록과 단원 범위 선택을 임시 데이터로 검증하고 정리한다.

이 자료는 식별 정보와 대단원 목차 DB다. 원문 지문·문제·예제·해설은 저장하지 않는다. 기존 출제는 선택한 단원의 학습 자료나 검수된 문제은행을 근거로 사용한다.
