# 교과서 카탈로그와 표지 매칭

2026-10-15 구현 기준. 사용자는 목차를 촬영하지 않고, 표지 사진이나 교재명으로 자기 교과서를 찾는다. 출판사·대표 저자·개정 교육과정·권/학기를 확인하고 단원·학습 범위를 선택한다.

## 현재 데이터

- 국어·영어·수학·사회·과학 총 **407종, 2,514개 대단원**. 초등학교 4~6학년 184종, 중학교 1~3학년 223종이다. 교육부를 포함한 20개 발행처를 구분한다. 기존 61종의 ID를 유지하고 346종을 추가했다. 본문은 포함하지 않는다.
- 미래엔 2022 개정 23종: 국어 신유식/민병곤 각 1~3학년 1·2학기 12종, 영어 문영인/수학 황선욱/과학 김태일 각 1~3학년 9종, 사회 손영찬 ①·② 2종.
- 비상교육 2022 개정 5종: 국어1-1 박현숙, 영어1 황종배, 수학1 이진호, 사회① 강창숙, 과학1 임태훈.
- 초등학교 4·5·6학년 2022 개정 33종: 각 학년 교육부 국어 1·2학기 가·나 4권, 미래엔 수학 장혜원/사회 전종한/과학 양일호 각 1·2학기 6권, 영어 강정진 1권. 학년당 11권이다. 교육부 국어는 미래엔 표기 검색도 허용하되 학기와 가·나 권을 구분한다.
- 기초 점검 자료 중학 5종·초등 15종은 실제 교과서와 분리한다. 교과서 후보로 매칭하지 않는다. 초등 자료는 학년별 자체 제작 노트를 출제 근거로 제공하며 전체 교과 내용을 제공하는 것은 아니다.
- 한국교과서협회 판매 목록의 대상 18개 출판사·283종을 출판사·대표 저자·개정판·학기/권별로 전부 대조해 연결했다. 해당 목록에 없는 자체 유통 미래엔 및 국정 교과서, 출판사가 공개한 추가 개정판도 포함한다. 2022 개정과 현재 중3 등이 사용하는 2015 개정을 별도 등록한다. [발행처별 범위·출처·검증 내역](15-publisher-coverage.md)을 참고한다.
- 세부 소단원이나 모든 과거 판본을 수집한 자료는 아니다. 목록 밖의 새 판본은 추가 요청으로 접수하며 다른 저자·개정판으로 대신 등록하지 않는다.

미래엔 원자료는 `apps/web/src/data/textbooks.json`의 교재별 `sourceUrl` 및 `tocSourceUrls`에 기록했다. [공식 중학 목록](https://22txbook.m-teacher.co.kr/book/list?lev=2)의 공개 목차 이미지를 읽고, 대표 저자를 대조했다. 사회②와 국어 2학기 차례는 각 페이지의 두 번째 차례 패널에서 구분했다. 초기 비상 데이터는 [공식 교과서](https://textbook.visang.com/home)의 교재별 차례가 출처다.

AI가 읽은 대단원 제목을 초기 자료로 사용하고, 저자 이름·학기·사회 권 번호·부록 제외 등은 대조해 정리했다. 원문 지문·예제·해설은 저장하지 않는다. 카탈로그에 오류가 있으면 관리자가 수정하고 revision을 올린다.

초등 원자료는 `apps/web/src/data/elementary-textbooks.json`에 기록했다. [미래엔 공식 초등 목록](https://22txbook.m-teacher.co.kr/book/list?lev=1)과 [공개 교과서 목록 API](https://e.m-teacher.co.kr/pages/ele/textbook/textbookList.ax?gradeCode=04&termCode=01&revisionCode=2022&sortCode=001), 교재별 공개 단원 API의 2022 개정 자료를 대조했다. `tocSourceUrls`에 정확한 교재별 단원 API와 확인한 차례 이미지 주소가 있다. 독도 별도 자료·과학 보완 자료는 본 교과서 단원에 합치지 않았으며, 영어는 Lesson 단위로 정리했다. 표지 인식 OCR이 추측한 저자명은 사용하지 않고 공식 교재 메타데이터로 확인했다.

## 서버 저장과 갱신

`textbooks/{catalogId}`에 교재 정보, 학교급(`elementary`/`middle`), 학년, 교육과정, 저자, 권/학기, 대단원, 출처, `revision`, `published`를 저장한다. 학교급이 없는 이전 기록은 중학교로 취급한다. 초등은 4~6학년, 중학은 1~3학년만 허용한다. 앱은 DB 자료를 우선 사용하며 동일 ID를 중복 노출하지 않는다. DB에서 비공개로 변경한 교재는 번들에 초기값이 있어도 다시 노출하지 않는다.

```sh
# 변경 계획만 조회 (기본)
node scripts/sync-textbook-catalog.cjs
# barum-10aad에 검증한 초기 카탈로그 등록
node scripts/sync-textbook-catalog.cjs --apply
```

동기화는 대상 Firebase 프로젝트를 확인한다. 이미 같은 해시이면 쓰지 않고, 수동 관리 자료는 덮어쓰지 않는다. 관리자 화면에서 저장하면 수동 관리로 바뀌어 다음 초기 데이터 동기화에서 보존된다. 학습자의 교재는 선택 시 스냅샷으로 복사하므로 중앙 목차를 수정해도 기존 학습 진도를 자동 변경하지 않는다.

## 매칭과 출제의 경계

표지 인식은 식별 정보만 읽고, 이미지에 보이지 않는 저자·개정판은 추측하지 않도록 요청한다. 검색과 후보 선정은 서버 카탈로그에 대해 수행한다. 명시된 학교급·학년·출판사·저자·학기·교육과정·가/나 권이 충돌하면 후보에서 제외한다. 가/나가 보이지 않으면 두 권을 후보로 보여 준다. 중학 사회의 ①·②는 권 번호이며 학년이 아니다. 불명확한 표지는 후보를 보여 주고 사용자에게 선택받는다. 후보 순위 점수는 인식 정확도 퍼센트로 표시하지 않는다.

등록 시 클라이언트가 만든 목차 대신 서버의 선택 교재를 다시 읽는다. 학습 범위와 사회 학년만 선택값으로 받는다. 같은 교재를 재등록해도 기존 본문과 범위를 초기화하지 않는다.

목차 연결은 완료됐지만, 목차만으로 교과서의 지문이나 내용을 아는 것은 아니다. 실제 AI 출제는 해당 단원의 등록 본문·학습 노트 또는 검수된 문제은행을 사용한다. 교과서 본문 자동 수집과 전 교육과정 공통 개념 자료 구축은 이 변경에 포함하지 않는다.

미등록 교재는 `textbookRequests`에 계정별·검색어별로 중복 없이 접수한다. 관리자 교재 목록에서 요청을 보고 공식 자료를 등록한 뒤 처리 완료로 변경한다.
