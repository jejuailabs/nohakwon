# 학습 체험 버전 — B 디자인 확정

2026-10-14 기준 첫 구현입니다. A/B 비교 후 사용자가 **B · 캐릭터 퀘스트**를 선택했습니다. 이후 제품 화면은 B의 남색·보라, 과목별 캐릭터와 퀘스트 구성을 기준으로 개발합니다. 현재는 브라우저 저장을 사용하는 학습 체험 버전입니다.

## 실행

Node.js 22 이상. 저장소 루트에서 `npm install`, `npm run dev`.
기본 주소는 `http://127.0.0.1:3000`이며 `/`는 `/b`로 이동합니다. B 화면에는 A/B 선택기를 표시하지 않습니다. A는 이전 시안 확인용으로 보존합니다.

| 주소 | 구성 |
| --- | --- |
| `/a` | 보존한 이전 시안: 민트·크림 컬러, 입체 마을, 과목별 진도 |
| `/b` | **기본 디자인**: 남색·보라 컬러, 과목별 캐릭터 5종, 오늘의 50문제, 파티·레벨·보상 |
| `?view=reviews` | 오늘 복습 및 이후 예정 문제 |
| `?view=notes` | 오답 및 북마크 |
| `?view=records` | 학습 횟수·정답률·연속 학습·최근 7일 기록 |
| `?subject=math` | 수학 선택. `korean`, `english`, `social`, `science`도 지원 |

포트를 변경하려면 `npm run dev --workspace=@nohakwon/web -- --port 3001`.
실서비스 배포는 기존 문서의 Vercel/Firebase 구성을 유지하며 이번 버전에서는 외부 배포나 Firebase 프로젝트 생성을 수행하지 않았습니다.

## 공통 기능

- 모든 문제·채점·자기평가·포인트·복습 계산은 두 디자인에서 같은 구현을 사용합니다.
- 샘플 문제는 과목당 10개씩 총 50개이며 정답·해설을 포함합니다. 문제은행/교과서별 배정은 아직 아닙니다.
- 정답 공개 전에 답안과 3단계 자기평가를 모두 선택합니다.
- 최초 복습 간격: 알겠어요+정답 21일, 알겠어요+오답 3일, 헷갈려요 14일, 모르겠어요 7일. 문서 05의 정규 모드 초기값을 사용합니다.
- 3초 미만 풀이에는 포인트를 지급하지 않습니다. 같은 문항의 당일 포인트와 일일 완료 보너스는 중복 지급하지 않습니다.
- 복습을 미리 연습해도 원래 복습 날짜는 유지되며 연습에는 포인트를 지급하지 않습니다.
- 50문항을 완료하면 보상 버튼으로 50포인트를 한 번 수령합니다.
- 별도 서버 없이 `localStorage` 키 `nohakwon:learning:v1`에 기록합니다. A/B 전환·새로고침 후에도 유지됩니다. 같은 출처의 다른 탭과도 동기화합니다.
- 서울 시간대를 기준으로 날짜별 진행률을 계산합니다. 페이지를 열어둔 경우에도 날짜 변경을 확인합니다.
- 저장소 차단·용량 부족·형식 손상은 사용자에게 알립니다.
- 모달의 기본 초점/Tab 이동/ESC 닫기는 네이티브 `dialog`로 처리합니다.
- 모바일은 한 열 배치와 하단 메뉴, 데스크톱은 디자인별 다단 배치를 사용합니다. 운영체제의 움직임 줄이기 설정과 프로필의 차분한 학습 모드를 지원합니다.

1. 확정된 B 디자인을 기준으로 나머지 페이지의 세부 화면 구현.
2. Firebase Google 로그인·서버 세션·보호자 프로필 저장 구현 완료. 상세 내용과 남은 권한 기능은 [12-firebase-accounts.md](12-firebase-accounts.md) 참고.

4. 검증된 문제은행·교과서/학년/단원별 배정, 체험용 복습 규칙과 실제 난이도 조절.

## 2026-10-15: B안 실제 학습 메뉴 확장

위의 비교 시연 설명은 초기 데모 기준입니다. 현재 로그인한 사용자의 B 화면은 `LearningWorkspace`에서 서버 채점과 Firebase 저장을 사용합니다. 정답·해설을 먼저 보여주고, 그 뒤에 3단계 이해도를 선택합니다.

교재·복습·오답노트·리포트·보호자·설정에 공통 `AdventureHeader`를 적용했습니다. 각 메뉴는 서재, 수련장, 기록실, 별자리, 베이스캠프, 준비실이라는 역할을 가지며 기존 다섯 동료의 일러스트와 과목 색을 재사용합니다. 실제 메뉴 이름과 주요 동작은 그대로 표시합니다.

- 교재·사진 인식 결과·복습 개념·오답·과목별 리포트에 같은 과목의 동료 초상과 색을 표시합니다. 수치는 실제 저장 데이터만 사용합니다.
- 학습 문제와 완료 화면에도 과목 동료를 표시합니다. 정답 공개와 이해도 저장 순서는 바꾸지 않습니다.
- 비어 있는 화면에서 다음 행동을 안내합니다. 특정 과목에 오답이 없으면 전체 과목으로 돌아갈 수 있습니다.
- 모바일에서는 동료의 작은 초상을 표시하고 현재 메뉴가 가로 내비게이션에 드러납니다. 차분한 모드는 큰 일러스트를 숨기고 작은 초상을 단순한 기호로 대체합니다. 라이트·기기 테마와 인쇄에서도 읽을 수 있도록 색을 조정합니다.
- 공통 구현: `components/adventure.tsx`, 스타일: `app/adventure.css`. 새 한국어 문구에는 영어·일본어·중국어 번역을 함께 제공합니다.

기존 58개 단위 테스트와 프로덕션 빌드를 통과했습니다. 임시 Firebase 프로필에서 사진 인식 결과의 최종 추가, 중복 방지, 범위 검증, 20권 제한과 동시 추가를 재검증했습니다. 실제 학습자의 교재와 학습 기록은 테스트 데이터로 덮어쓰지 않습니다.
