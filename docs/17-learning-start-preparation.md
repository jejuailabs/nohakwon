# 교과서 등록 후 첫 학습 준비

2026-10-16 수정. 교과서 사진으로 카탈로그를 매칭한 계정에서 첫 학습을 시작하면 `/api/learn`이 409를 반환하던 문제를 수정했다.

## 원인

1. 카탈로그는 출판사·개정판·목차만 가지고 있다. 본문이 없는 교재를 `replenishQuestions`가 전부 건너뛰어 출제 작업이 없었다.
2. 출제 작업을 만들어도 `accepted === 0`만으로 대기·실행 중인 작업까지 실패 작업처럼 30분간 건너뛰었다.
3. 클라이언트는 준비 중인 상태를 처리하지 않았고, 처음 누른 버튼에서 멀리 떨어진 상단에 일반 오류만 표시했다.

## 동작

- 학습 시작은 준비가 필요하면 HTTP 202와 작업 상태를 반환한다. 화면은 진행 단계를 표시하고 동일한 요청 ID로 조회하여, 검증 문항이 준비되면 자동으로 기존 학습창을 연다.
- 등록한 본문이 있으면 그 본문을 우선한다. 카탈로그 교재에 본문이 없으면 공식 출판사·교수자료·국가교육과정·EBS의 공개 자료에서 단원 범위를 확인하고 자체 개념 설명과 예문을 준비한다. 출처가 확인되지 않은 임의 목차나 수정한 단원에는 본문 추가를 안내한다.
- 공개 자료 조회는 [Responses API web search](https://developers.openai.com/api/docs/guides/tools-web-search)의 도메인 제한·실제 조회 출처 목록을 사용한다. 모델이 작성한 참고 URL을 그대로 믿지 않고 실제 도구에서 확인한 허용 도메인의 주소와 대조한다. 비상의 기존 전시관과 공식 교수자료인 비바샘은 별도 도메인으로 연결한다.
- 자동 작성한 개념 자료는 별도 검색·검토를 통과해야 저장한다. 검증된 공개 자료는 `curriculumMaterials`에 재사용 가능하게 보관하고 학습자별 `learningMaterials`에 사본을 저장한다. 개인 업로드 본문은 공용 자료로 자동 공개하지 않는다.
- 일부 범위에는 미리 검토한 자체 개념 설명을 사용한다. 중1 수학의 수와 연산·소인수분해·정수와 유리수는 [EBS 중1 학습 범위](https://mid.ebs.co.kr/premium/product/view?productId=445146)와 [세부 학습 주제](https://mid.ebs.co.kr/course/view?courseId=100005120&left=)를 대조했다. 학년과 단원 이름이 정확히 일치하는 경우에만 매칭하며 다른 학년이나 사용자 수정 제목으로 확장하지 않는다.
- 공식 소단원 범위를 미리 확인한 경우에는 매번 검색하지 않는다. 비상 영어1(황종배, 2022개정)은 [비바샘 단원별 문법 안내](https://v.vivasam.com/themeplace/engactivity/supplement.do?level=M1)의 8개 Lesson을 저자·개정판·단원명별로 매칭한다. 사회①의 ‘세계화 시대, 지리의 힘’과 과학1의 ‘과학과 인류의 지속가능한 삶’은 각각 [EBS 사회 개념 범위](https://mid.ebs.co.kr/course/view?courseId=100006173&left=), [EBS 과학 개념 범위](https://mid.ebs.co.kr/course/view?courseId=100006176&left=grade)를 대조했다. 이 범위로 설명·자체 예문을 작성한 뒤 별도 정확성 검토를 수행한다.
- 교재의 `units[].source`에는 수집한 교과서 원문처럼 자동 자료를 넣지 않는다. 학습지도·문항·풀이 이력에 `sourceKind=curriculum`과 출처를 기록하고, 화면에서 **단원 공통 개념 연습·자체 예문**임을 구분한다. 작품·지문 자체의 독해 문제는 해당 본문이 필요하다.
- 기존의 유형 분석·원문 인용 확인·독립 풀이 정답 검증을 유지한다. 첫 문항 묶음이 전부 검수 대기이면 새 변형으로 한 번만 더 생성하며 검증 조건은 완화하지 않는다.
- 준비창을 닫으면 자동 이동만 멈춘다. 이미 시작한 작업은 계속되고 같은 학습을 다시 시작하면 완료된 문항이나 기존 작업을 재사용한다. 작업 실패·검수 통과 0개·본문 누락은 구체적으로 안내한다.

## 검증

`npm test`, 프로덕션 빌드와 기존 학습·적응 학습 통합 검증을 수행한다. `node scripts/verify-learning-start.cjs --live`는 임시 학습자로 실제 국어·수학의 카탈로그 등록, 첫 요청의 202, 반복 요청의 작업 재사용, AI 출제·검증, 답안 비공개, 본문 우선, 기존 회차 재개를 확인한다. `--all-subjects`는 영어·사회·과학도 함께 확인한다. 임시 학생·계정·사용량 기록은 정리하며 기존 학생의 답안·포인트·진도를 테스트 값으로 바꾸지 않는다.
