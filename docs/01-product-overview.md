# 01. 제품 개요

## 1. 제품 목표

교과서별 진도에 맞춰 매일 핵심 문제를 풀고, 학생의 **정답·자기평가·복습 결과**를 누적해 부족한 개념을 반복 보완하는 저비용 구독형 학습 서비스.

## 2. 사용자 유형

| 유형 | 설명 | 주요 화면 |
|---|---|---|
| 학생 | 중1~3, 매일 문제 풀이·복습 | 오늘의 학습, 오답노트, 예정 복습, 연속 학습일 |
| 학부모(보호자) | 가입·자녀 프로필 생성·설정·리포트 열람·결제 | 자녀 관리, 리포트, 구독 |
| 관리자 | 교과서·문항·사용자·비용 관리 | 어드민 대시보드 (문서 08) |

> 한 명의 보호자가 여러 자녀를 등록할 수 있습니다. 학생 계정 방식은 [04-auth-and-roles](04-auth-and-roles.md) 참고.

## 3. 학습 설정 항목 (학생별)

- 학교(선택, 최소 정보), 학년
- 과목별 교과서 출판사·판본
- 과목별 현재 학습 단원 (진도 시작점)
- 학습 과목 on/off, 과목별 일일 신규 문제 수 (기본 10)
- 과목별 초기 난이도 (1~5) 또는 진단 문제로 결정
- 난이도 자동 조절 on/off

## 4. 기능 범위

### 4.1 1차 MVP (명세서 16장 기준)

- [ ] 1학년 5과목
- [ ] 주요 교과서 목차 매핑
- [ ] 문제은행 (객관식·단답형)
- [ ] 일일 50문제 출제 + 복습 (최대 100)
- [ ] 3단계 자기평가 + **솔직함 보상(칭찬·포인트)**
- [ ] 7일 체험 압축 복습
- [ ] 주간 미니시험
- [ ] 오답노트
- [ ] 학부모 리포트 (체험 종료 리포트 + 주간)
- [ ] 월 5,000원 결제
- [ ] 4개 국어 UI, 다크/라이트 모드, Google 로그인
- [ ] 어드민 대시보드

### 4.2 MVP 이후

- 2·3학년 확장 (데이터 구조는 처음부터 학년 확장 가능하게)
- 서술형 문항 및 채점
- 중간·기말 특화 모의시험 (부가 유료 상품 실험)
- 상세 학부모 분석, 추가 시험지
- 월간 리포트

### 4.3 범위 밖 (명시적으로 하지 않는 것)

- 교과서 본문 전체 수집
- AI 모델 자체의 강화학습 ("강화학습"은 서비스 표현으로만 사용 가능, 실제 구현은 간격 반복 + 적응형 출제)
- 실제 시험 적중 보장
- 학생의 성격·지능 판단

## 5. 일일 학습 흐름

```
로그인
 → 오늘의 학습 (과목별 신규 10문제 + 복습)
 → 문항별 답안 제출 → 자동 채점
 → 자기평가 3단계 선택 (완전히 알았다 / 알쏭달쏭하다 / 전혀 모르겠다)
 → 즉시 해설 확인
 → 복습 일정 생성
 → 일일 요약
```

> 채점과 자기평가 순서: 명세서는 "답안 제출·채점 → 자기평가"입니다. 자기평가를 **정답 공개 전**에 받아야 자신감 측정이 왜곡되지 않으므로, 구현은 `제출 → 자기평가 선택 → 정오·해설 공개`로 하는 것을 제안합니다. ⚠️ 확인 필요

## 5.1 핵심 동기 설계: 솔직함 보상

"모른다"고 솔직하게 표시하면 칭찬과 포인트를 받습니다. 복습을 피하려고 전부 "안다"를 고르는 행동을 막기 위한 장치이며, 포인트를 노리고 "모르겠다"를 골라도 복습이 배정되므로 학습 효과는 유지됩니다. 상세: [05-learning-engine](05-learning-engine.md) §3.6

## 6. MVP 검증 지표

| 지표 | 정의 (제안) |
|---|---|
| 7일 완주율 | 체험 시작자 중 7일차 주간 시험 완료 비율 |
| 복습 참여율 | 배정된 복습 문항 중 당일 풀이 비율 |
| 개념별 개선율 | 첫 풀이 오답 개념 중 재복습 정답 전환 비율 |
| 유료 전환율 | 체험 종료자 중 결제 완료 비율 |
| 학생당 AI/인프라 원가 | 월 AI 토큰비 + 인프라비 ÷ 활성 학생 수 |
| 문항 오류율 | 이의제기 인정 또는 비활성화 문항 ÷ 노출 문항 |
| 솔직 표시율 | 전체 자기평가 중 unsure·unknown 비율 (지나치게 낮으면 "전부 안다" 패턴 의심) |
| 극복 전환율 | unsure·unknown 표시 개념 중 복습 정답으로 전환된 비율 |

## 7. 용어집

| 용어 | 정의 |
|---|---|
| 성취기준 | 교육과정의 공식 성취기준 코드. 출판사와 무관한 공통 개념 축 |
| 개념(concept) | 성취기준 하위의 출제 단위. 숙련도 추적의 기본 단위 |
| 단원/소단원 | 출판사·판본별 교과서 목차 항목 |
| 변형문항 그룹 | 같은 개념·구조의 동형/변형 문항 묶음 |
| 복습 대기열 | 학생별로 예정된 복습 항목 목록 |
| 숙련도(mastery) | 학생 × 개념 단위의 누적 상태 (정답률, 연속 성공, 현재 난이도 등) |
| 체험 모드 | 가입 후 7일, 압축된 복습 간격 적용 |
| 솔직함 포인트 | "알쏭달쏭·모르겠다"를 고른 행동에 주는 포인트. 정답 여부와 무관 |
| 극복 보너스 | 솔직하게 표시했던 개념을 복습에서 맞혔을 때 주는 더 큰 포인트 |
