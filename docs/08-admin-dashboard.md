# 08. 어드민 대시보드

> 화면 디자인은 별도 제공 예정입니다. 이 문서는 **메뉴 구조, 기능, 데이터 소스, 권한**만 정의합니다.

## 1. 접근

- 경로: `/[locale]/admin`
- Google 로그인 + Custom Claims `admin: true` 필수 (문서 04)
- 권한 없는 사용자에게는 404 반환
- 모든 쓰기 작업은 Route Handler 또는 Callable Function 경유, `adminAuditLogs` 기록
- 다크/라이트·다국어는 서비스와 동일한 시스템 사용

## 3. 화면별 기능

### 3.1 개요 (KPI)

데이터 소스: `statsDaily/{YYYY-MM-DD}` (매일 새벽 Functions 집계)

| 카드 | 정의 |
|---|---|
| 활성 학생 수 | 최근 7일 1문항 이상 풀이 |
| 오늘 풀이 수 / 평균 완료율 | |
| **7일 완주율** | 문서 01 §6 |
| **복습 참여율** | |
| **개념별 개선율** | |
| **유료 전환율** | |
| **학생당 AI/인프라 원가** | AI는 `aiUsageLogs` 집계, 인프라는 수동 입력값 |
| **문항 오류율** | |
| 문제은행 적중률 | 배정 문항 중 기존 은행 문항 비율 |
| 솔직 표시율 / 극복 전환율 | 문서 01 §6. 학생별 "전부 known" 비율 상위 목록 제공 |
| 포인트 발행량 | 유형별(솔직함·극복·완료) 일별 합계 |

기간 필터(7일/30일/사용자 지정), 학년·과목 필터, 추이 차트.

### 3.2 교과서·목차 매핑

- 교과서 목록 (학년·과목·출판사·판본·상태·매핑 버전)
- 목차 트리 편집기: 대단원/소단원 추가·순서 변경·성취기준 연결·개념 연결
- 자동 수집 결과(`draft`) 비교 후 승인
- CSV 가져오기/내보내기
- 판본 변경 시 새 `mappingVersion` 생성, 학생 이관 도구

### 3.3 성취기준·개념

- 성취기준 코드 등록, 개념 생성, 선수개념 연결 (그래프 보기)
- 개념별 문항 수(난이도별) 표시 → 부족 칸 강조 → "AI 생성 요청" 버튼

### 3.4 문제은행

- 필터: 학년, 과목, 교과서, 단원, 개념, 난이도, 유형, 상태, 출처, 이의제기 수
- 문항 상세: 본문·선지·시각자료 미리보기(라이트/다크), 정답·해설, 태그, 통계(노출 수, 정답률, 평균 시간, 보정 난이도)
- 편집, 상태 변경(비활성화), 변형 그룹 관리
- 시각자료 편집기: VisualSpec JSON + 실시간 미리보기 + 자동 검사 결과

### 3.5 검수 대기열

- `needs_review` 문항을 순서대로 표시
- 자동 검증 결과(독립 풀이 일치 여부, 유사 문항 경고) 함께 표시
- 승인 / 수정 후 승인 / 반려(사유 선택) — 키보드 단축키 지원
- 검수자별 처리량 통계

### 3.6 이의제기

- 학생 신고 목록 (사유: 정답 오류, 해설 오류, 선지 오류, 기타)
- 인정 시 문항 수정 또는 비활성화, 해당 문항 오답 처리된 학생 attempt 정정 여부 선택 ⚠️ 정정 정책 확정 필요

### 3.7 AI 작업·비용

- `aiJobs` 목록: 상태, 재시도, 결과 문항 링크
- 수동 생성 요청: 개념·난이도·유형·개수
- 비용: 기간별 목적·모델별 토큰 합계 × `appConfig.pricing` 단가 × 환율 → 원화 추정
- **단가 미입력 시 "단가 미확인" 표시, 금액 계산하지 않음**
- 100문항 평가 셋 실행 결과 비교 표 (문서 06 §8.3)

### 3.8 사용자·학생

- 보호자 검색 (이메일), 연결된 학생 목록
- 학생 상세: 설정, 학습 요약, 체험/구독 상태 — 개인정보는 최소 표시, 열람 시 감사 로그
- 작업: 진도 수정 지원, 체험 연장, 계정 삭제 요청 처리

### 3.9 구독·결제

- 구독 상태별 목록, 결제 실패(past_due) 목록, 환불 처리 기록
- PG 대시보드 링크 (PG 확정 후)

### 3.10 리포트

- 발행된 리포트 검색, 재생성, 템플릿 문구(4개 국어) 관리

### 3.11 학습 엔진 설정 (`appConfig/main`)

- 일일 신규 기본값, 일일 최대(100)
- 정규·체험 간격 반복 수치, 보정 계수, weakness 가중치
- 난이도 조절 임계값, 쿨다운, 학년별 범위
- 솔직함 보상 포인트 값, 극복 보너스, 최소 풀이 시간 (`appConfig.rewards`)
- 저장 시 변경 전/후 diff 확인 + 감사 로그, 버전 이력 보관

### 3.12 관리자 관리 (owner)

- 이메일로 관리자 추가, 역할 변경, 해제 (`setAdminRole` Callable)
- 변경 후 대상자에게 재로그인 필요 안내

## 4. 기술 메모

- 목록 화면은 서버 컴포넌트 + 커서 페이지네이션 (Firestore `startAfter`)
- 대량 집계는 화면에서 하지 않고 `statsDaily` 등 집계 문서만 읽음
- 차트 라이브러리: 디자인 확정 후 선택 (예: Recharts)
